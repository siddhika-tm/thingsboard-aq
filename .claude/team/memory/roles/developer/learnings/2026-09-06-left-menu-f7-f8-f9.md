# Left menu — test-loop iteration 1 (F-7 / F-8 / F-9)

**Date:** 2026-09-06 · **Work item:** left-menu-and-favicon

## Flattening a menu section can crash code that never reads the menu

Moving `alarms`, `alarm_rules`, `notification_inbox`, `widget_library` to top-level
`type: 'link'` entries broke `router-tabs.component.ts`, a file with no obvious link to
the menu components. `findRootSection` matches on **path suffix** over the *built menu
sections*, so a flattened leaf now matches routes it never matched before — and
`buildTabs` dereferenced `found.pages` unguarded while `MenuSection.pages` has always
been declared optional (`pages?:`, menu.models.ts:30).

**Lesson:** when changing a shared *model*, grep for every consumer that walks it, not
just the components that render it. TypeScript did not catch this because `found` is
typed non-nullable — the optionality was one level deeper, on a field.

**Lesson:** the right fix for "X is now optional in practice" is to honour the type's
own declared optionality, not to add a defensive `?.` and move on. Ask what the feature
*should* render in the new shape. Here: a leaf section owns no sub-pages -> no tab strip,
which the template's existing `.length > 1` guard already handled.

## A CSS fix can measure right and still be geometrically wrong

F-8 looked like one declaration (`width: 100%`). It took three, each found only by
re-measuring in the browser after the previous one:
1. `width: 100%` — anchor was 48px but at x=24..72, overflowing the 64px rail.
2. `margin-left/right: 0` — the expanded row's 8px side margins were still applying.
3. `gap: 0` — the label span collapses to zero width, but the 12px flex gap still
   applied *beside* it, leaving the icon centred at x=34 rather than the x=40 rail axis.

**Lesson:** verify the acceptance number AND the surrounding geometry. "48x40" passed
after step 1 while the pill hung off the rail edge. Measure the parent, the child, and
the centre — not just the box the criterion names. (The icon was off-axis at 34 even in
the frozen tree; the shrink-wrapped anchor hid it.)

## Winning a cascade fight without `!important`

`popover.component.scss` nests to `.tb-popover.tb-menu .tb-menu-content
.mat-mdc-button:not(.mat-mdc-icon-button)` = **0,5,0** (`:not()` contributes its
argument's weight — the run-2 report's 0,4,0 undercounted it). Beat it at **0,5,1** by
qualifying our own panel's second class (`&.tb-menu-content`) plus the element type.
Count the specificity of the *full nested* selector, not the innermost line.

## Keeping a tracked file provably clean

`proxy.conf.js` must end clean, and `sed -i` dirties it via LF->CRLF on Windows. Instead
of editing-then-reverting, generate an out-of-tree copy and pass
`ng serve --proxy-config /tmp/proxy.dev.js`. The tracked file is then clean *by
construction* — no revert step to forget, nothing to verify after the fact.
