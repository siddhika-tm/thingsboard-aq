- A 1px header-band delta is usually browser table rounding, not a CSS bug: in `display: table` a row's `height` is a MINIMUM and the cell border is distributed +-1px per page. Prove it by reverting to the upstream value - if the split persists at every height, it is not the diff. `2026-09-05-g3-run2-grid-fidelity.md`
- A route-level `querySelector` can match the PREVIOUS page's still-mounted widget (a "/users header is 9.5px" alarm was the home dashboard's alarms widget). Assert `closest('tb-entities-table')` before reporting any per-route measurement. `2026-09-05-g3-run2-grid-fidelity.md`
- Locate table cells by HEADER ORDINAL, never by `columns[]` index arithmetic - a leading selection/action column shifts it and silently reports the wrong column. `2026-09-05-g3-run2-grid-fidelity.md`
- Driving the real component via `ng.getComponent(host)` exercises states live data never produces (all demo alarms are CRITICAL, so warning/neutral tones would go untested). To stub an rxjs Observable there, clone a real instance's prototype - a hand-rolled `{subscribe,pipe}` throws `Unable to lift unknown Observable type`. `2026-09-05-g3-run2-grid-fidelity.md`
- A rule that EXISTS may never APPLY: 4 of 5 G3 findings were correct CSS outranked by a pre-existing deeper-nested selector (`.tb-default .mat-mdc-table .mat-mdc-header-row` (0,3,0) beats `.tb-default .mat-mdc-header-row` (0,2,0); `!important` does not rescue lower specificity). Assert `getComputedStyle`, never stylesheet text; prove the diagnosis by injecting the same declaration at higher specificity and re-measuring. `document.styleSheets.cssRules` is empty for Angular component sheets - use the DOM experiment. `2026-09-05-g3-run1-grid-fidelity.md`
- Selector families are build-specific: this build renders `<mat-row>`, not `<tr class="mat-mdc-row">` - a `tr`-only selector times out and mimics "page never loaded". Always `'mat-row, tr.mat-mdc-row'`. Scope drawer/tab probes to `.mat-mdc-tab-body-active` or you silently measure the background grid. `2026-09-05-g3-run1-grid-fidelity.md`
- Before raising a dark-leak or similar probe hit, confirm it is VISIBLE (`opacity`/`visibility`) and that the diff touches it - `mat-button-toggle-focus-overlay` at `opacity:0` is a false positive. `2026-09-05-g3-run1-grid-fidelity.md`
- Lint delta by file:line:rule, but tolerate pure line shifts: equal counts hid 3 entries that had merely moved +4 lines under inserted markup. `2026-09-05-g3-run1-grid-fidelity.md`
- A known pre-existing env failure can mask a criterion: `mvn install` aborted at `netty-mqtt` (Docker absent) BEFORE reaching ui-ngx, proving nothing about the diff - re-run with `-DskipTests`, and read BUILD SUCCESS from the log (an `echo $?` after a redirect reports the echo). `2026-09-05-g3-run1-grid-fidelity.md`
- Weigh reachability before severity: the suspected pager-clamp gap (candidate High) PASSED - every reachable shrink path resets `pageIndex=0` upstream. `2026-09-05-g3-run1-grid-fidelity.md`
- Write expected results from the IMPLEMENTED code, not from the AC text: on the grid work, AC-20's bold range was deliberately dropped, the count badge hides at total 0, and the neutral chip uses `--aq-hover` not a tint — three false findings avoided. `2026-09-05-g27-test-case-drafting.md`
- Never trust a stated blast radius: `tb-entities-table` has **46** consumers (39 routed + 7 wrapper in drawer tabs/dialogs), not the "7 additional"/"10+" the requirement and design claim. Delegate the inventory to a search subagent; it reshapes the regression tier.

Mark N/A from observed DOM, not from the config flag.
